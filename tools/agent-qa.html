نبذة

حزمة لضمان جودة وكلاء الذكاء الاصطناعي تنسّق خطط اختبار باللغة الطبيعية لواجهات API وCLI والمتصفح والأجهزة المحمولة، وتحفظ أدلة الفيديو والشبكة، وتوفر واجهتي CLI وMCP عبر stdio. الإصدار الحالي متاح المصدر بترخيص FSL-1.1-ALv2 ويتحول إلى Apache-2.0 بعد عامين من نشره؛ وقد يفرض مزودو النماذج والمتصفح والأجهزة رسوماً منفصلة.

QA toolkit for AI agents that coordinates natural-language API, CLI, browser, and mobile test plans, retains video and network evidence, and exposes CLI and MCP stdio interfaces.
