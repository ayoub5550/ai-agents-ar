نبذة

GitHub Copilot هو مساعد البرمجة بالذكاء الاصطناعي الأكثر استخداماً. يقدم اقتراحات كود ذكية في الوقت الحقيقي، يجيب على أسئلة البرمجة، ويساعد في كتابة الاختبارات والتوثيق. متاح في VS Code وJetBrains وNeovim.

The industry-standard AI coding assistant — intelligent autocomplete, PR summaries, and code generation in VS Code and JetBrains.
